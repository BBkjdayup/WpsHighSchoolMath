# WPS 高中数学工具 0.9.0 完全免费版验收记录

## 安装及升级

**从 0.8.1 升级时先备份收藏。** 在仍开着的文字和演示编辑器中分别打开「我的绘图收藏 → 迁移备份与撤销」，导出备份文字并复制到文本文件。保存文档、退出 WPS，然后运行 EXE。使用 ZIP 时先完整解压，再双击 `install.cmd`。安装后在新版「我的绘图收藏」中合并导入。已写入试卷或课件的插件函数图可以直接载入参数。
